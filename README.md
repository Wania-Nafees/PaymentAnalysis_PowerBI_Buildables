# PaymentAnalysis_PowerBI_Buildables
SynthCart Payment Analysis | Power BI Dashboard: 
This project leverages Power BI to analyze and visualize payment transaction data for SynthCart, providing actionable insights into payment trends, customer behavior, and revenue patterns.

Highlights:
Interactive dashboards with filters for payment type and time, Revenue trends and payment method performance insights, Key KPIs: total transactions, average payment value, Installments.

Technologies: Power BI, DAX, Data Modeling, Data Visualization
